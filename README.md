# Bookkeeping Sheets – embeddable calculators

Free small business calculators from [bookkeepingsheets.com](https://bookkeepingsheets.com/) that anyone can embed on their own site.
Each calculator lives at `/<slug>/` and links back to its full page with formulas and worked examples.

Built by `build.py` from `calcs.json`. Font: Manrope (SIL Open Font License 1.1).
